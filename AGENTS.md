# Инструкции для DeepSeek Harness

## Контекст проекта

- Проект: десктопное Windows-приложение для сборки тома проектной документации по ГОСТ Р 21.101-2020.
- Стек: Python 3.12, PySide6/Qt, QWebEngineView + QWebChannel, python-docx, PyMuPDF, pywin32/Word COM.
- Точка входа: main.py.
- Основная спецификация и актуальные решения: SPEC.md.
- Пакет приложения: app/; зависимости поставляются в vendor/.
- Временные результаты, изображения и логи находятся в tmp/.

## Как начинать новую сессию

1. Сначала прочитать только этот файл и SPEC.md (при необходимости — последние изменения в Git).
2. Не сканировать весь каталог и не читать рекурсивно vendor/, tmp/, __pycache__/, PDF, изображения и бинарные файлы.
3. Для конкретной задачи найти точку входа через адресный поиск по app/ и читать только относящиеся к задаче файлы.
4. Не перечитывать уже просмотренные файлы без причины. Если контекст задачи неизвестен, сначала кратко сформулировать, каких данных не хватает.
5. Перед изменением существующего файла прочитать его актуальное содержимое; после изменения проверить только затронутый сценарий.

## Правила разработки

- Не менять публичное поведение без проверки требований в SPEC.md.
- Правила ГОСТ, шрифты, поля и параметры оформления должны оставаться конфигурируемыми; не дублировать их без необходимости в коде.
- Сохранять UTF-8 и русский текст.
- Не редактировать содержимое vendor/ без отдельного явного запроса.
- Не коммитить временные результаты из tmp/, кэш Python, профили браузера и сгенерированные PDF/PNG/DOCX.
- Для изменений UI учитывать связку Python ↔ HTML/JavaScript через QWebChannel.
- Для экспорта проверять отдельно DOCX/PDF и не считать успешный запуск приложения доказательством корректности экспорта.

## Подсистема оформления

- Геометрия основной надписи (формы 3/5/6) — единый источник `app/core/geometry.py`.
- **Графа 9** (организация) заполняется ТЕКСТОМ по центру ячейки ЛИБО ЛОГОТИПОМ из PDF:
  режим и файл — в `project.stamp_cell9` (модель, сохраняется в JSON), настройка —
  в форме реквизитов (панель справа). Подробности и координаты ячейки — в SPEC.md.
- Логотип: PDF растеризуется в PNG модулем `app/core/logo.py` (обрезка белых полей,
  кэш в `tmp/logo_cache`), затем вписывается в ячейку с сохранением пропорций.
  В HTML — `object-fit:contain`, в Word/PDF — расчёт размера в мм.
- Длинный текст в графе 9 уменьшает кегль: в HTML — автоподгонка `fit-lbl`,
  в PDF — подбор кегля. Не дублировать эту логику в новых выводах.

## Быстрые команды

- Запуск: python main.py или run.bat.
- Установка/обновление локальных зависимостей: python bootstrap_deps.py.
- Спецификация: SPEC.md.
