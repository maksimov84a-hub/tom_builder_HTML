# Окружение: версия Python

## Рабочая версия

**Python 3.12 (64-бит, Windows).** Проверено на 3.12.10 и 3.12.13.

```bat
winget install Python.Python.3.12
```

После установки:

```bat
py -0p                :: список установленных версий
py -3.12 --version    :: Python 3.12.x
run.bat               :: запуск приложения
```

## Почему именно 3.12

Зависимости поставляются готовыми в `vendor/` (собраны скриптом
`bootstrap_deps.py`, pip в этой среде ограничен) и содержат **бинарные модули
только под CPython 3.12**:

| Пакет | Файл в `vendor/` |
|-------|------------------|
| lxml 6.1.3 | `lxml/etree.cp312-win_amd64.pyd` |
| pywin32 312 | `win32com/*.cp312-win_amd64.pyd` |
| PySide6 6.11.2 | колёса `cp310-abi3` (совместимы с 3.10+) |
| PyMuPDF 1.28.2 | колёса `cp310-abi3` (совместимы с 3.10+) |

Файлы `.pyd` привязаны к конкретной версии интерпретатора: на другой версии
Python их нельзя импортировать. На Python 3.14 импорт падает с

```
ImportError: cannot import name 'etree' from 'lxml'
```

из-за чего не загружается `python-docx` (он строится на lxml) и **записка не
отображается в предпросмотре**. PySide6 и PyMuPDF (abi3) при этом работают,
поэтому PDF показывается, а DOCX — нет: это и есть признак неверной версии.

## Другие версии Python

Запуск на 3.13/3.14 без пересборки `vendor/` **не поддерживается**.
Если нужна другая версия — пересоберите зависимости под неё:

```bat
py -3.14 bootstrap_deps.py py314
```

Учтите: при `py314` функция `compatible()` в `bootstrap_deps.py` пропускает
любой `win_amd64`-wheel и может взять `cp312`-сборку lxml — фильтр по `cp314`
нужно добавить, иначе ошибка повторится.

Свой интерпретатор можно указать переменной окружения:

```bat
set TOM_PYTHON=C:\путь\к\python.exe
run.bat
```

## Что это ломает, если версия неверная

| Возможность | На 3.12 | На другой версии |
|-------------|---------|------------------|
| Предпросмотр листов DOCX | работает | падает (пустая заглушка) |
| Оглавление записки | работает | не строится |
| Правка текста ПЗ в предпросмотре | работает | недоступна |
| Оформление абзацев и списков из Word | переносится | теряется |
| Графика и приложения (PDF) | работают | работают (PyMuPDF — abi3) |
| Интерфейс (PySide6) | работает | работает (abi3) |

Признак проблемы в приложении: на листе записки вместо текста написано
«Не удалось отобразить содержимое файла» или «Сбой предпросмотра», в
`tmp/build.log` — `ImportError ... lxml`.
