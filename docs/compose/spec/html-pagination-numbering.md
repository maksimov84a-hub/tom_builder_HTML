## [S1] Problem

1. **Слишком много незанятого места в листах HTML.** `_estimate_paragraph_h`
   (`app/core/preview_html.py:197-198`) переводит интервалы абзаца из пунктов
   в миллиметры умножением на `PT_PER_MM` (2.835 пт/мм) — это перевод
   **мм→пт**. Интервал 8 pt оценивается как 22.7 мм вместо 2.8 мм (~×8),
   бюджет листа исчерпывается рано, листы обрезаются на середине.
2. **«Лист / Листов» в формах 5/6 показывают не те числа.**
   - предпросмотр одного документа: номер — по документу, «Листов» —
     общее число листов тома (рассинхрон);
   - «Собрать том в HTML»: номера сквозные по тому, а по требованию
     в формах 5/6 должны быть **листы только этого раздела (части)**.

## [S2] Design

**Пункт 1 — единицы.** В `_estimate_paragraph_h` интервалы конвертируются
делением: `height += (space_before_pt + space_after_pt) / PT_PER_MM`
(`PT_PER_MM = 72/25.4` — пунктов в одном мм). Остальная модель высот
(строки, line-height, бюджет = бокс листа − padding 6+6 мм) не меняется.

**Пункт 2 — нумерация.** В HTML-предпросмотре и HTML-сборках:

- графы **«Лист»/«Листов» форм 5/6** (содержание, ПЗ, лист изменений)
  = позиция листа **внутри раздела** и **число листов раздела**
  (`_section_sheet_count`); счётчик раздела стартует с 1;
- **квадрат сквозной нумерации** (правый верхний угол) и **номера листов
  в строках оглавления ПЗ** в «Собрать том в HTML» остаются сквозными
  по тому (согласованы с содержанием): реализация через
  `snapshot["square_base"]` —
  первый номер раздела из `toc.build_layout`; квадрат = base + локальный − 1.
  В раздельных сборках/предпросмотре раздела base не задаётся — квадрат
  локальный (как сейчас);
- предпросмотр одного документа ПЗ: счётчик с сдвигом = листы, стоящие
  перед документом в разделе (листы оглавления + предыдущие документы),
  «Листов» = число листов раздела ПЗ;
- предпросмотр одного листа «Содержание»/«Изменения»: «Лист 1 /
  Листов N» раздела;
- обложка/титул — без номеров (как сейчас).

**Не меняется:** DOCX/PDF-экспорт (Word-путь рисует пустые графы «Лист» —
известное ограничение; PyMuPDF-fallback — сквозная по тому), содержание
тома, дерево, индикатор «Листов: N».

## [S3] Out of Scope

- Заполнение граф «Лист/Листов» в Word/PDF-экспорте (отдельная задача).
- Пагинация листа изменений (>20 записей) и таблиц с занижением оценки.
- Изменение модели высот строк/символов (кроме ошибки единиц).
